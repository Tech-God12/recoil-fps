# Recoil FPS — hostile playtest audit (2026-09-24)

## Method and limits (written **before production changes**)

I started the Vite server on `0.0.0.0:5173` and verified HTTP 200. This sandbox has **no Chromium, Firefox, WebKit, Playwright or Puppeteer executable/package**. I did **not** pretend to have seen the current game's pixels, played with a mouse, heard the mix, measured GPU FPS, or captured new screenshots. The older `docs/screenshots/` are historical, not evidence of today's build. Instead I ran `node scripts/audit-play.mjs`: it constructs **both actual mission worlds and the arena**, ten actual gun geometries/stats, the live 9-bot TDM manager and a 10-pool/3-active mission AI scene; drives their updates, simulates two spawn collapses against actual occluder raycasts, advances mission rules, and server-renders home, loadout, settings, boot, mission objective, pause, TDM setup, ranked setup and results. Screenshots and audio/hardware playtesting remain a separate acceptance gate.

The headless baseline (seed 127; see `scripts/audit-play.mjs` and `/tmp/recoil-audit-before.log` during this run): Sandblast **20 visible world draws / 110,150 triangles / 2,266 solids / 331 windows / 40 cover nodes**; Town **19 / 63,418 / 1,900 / 260 / 40**; Warehouse **27 / 43,666 / 221 / 0 / 40**. The 10 factory weapons range **28–44 draws** and **13,906–47,217 triangles**, including arms. Nominal *all-body-hits* M416/SCAR/AWM/SPAS times-to-kill at 10 m: missions **0.154/0.100/1.250/0 s**, TDM light armor **0.385/0.300/2.500/0.750 s**. The SPAS estimate unrealistically assumes every pellet connects. In eight simulated TDM seconds, all **9** bots advanced through PATROL/ENGAGE/PUSH, with **9** gun reports; one unobstructed 3-soldier mission sim produced **17** reports, **6** damage calls, and an alert→engage transition. Node update timings (TDM mean ~0.38 ms, p95 ~0.82 ms per 30-Hz tick; mission mean ~0.03 ms) omit WebGL, canvas drawing, audio, React and actual renderer draw calls; they are **not FPS**.

**Crucial reproduction:** with five opponents at the approaches to Alpha's yard, **80/80** player respawns were visible to an opponent within 30 m. With opponents on the five spawn pads, **76/80** were visible within 30 m and **80/80** landed within 8 m; nearest separation **1.0 m**. This is a controlled worst case, not a claim about ordinary match frequency. The existing algorithm only maximises enemy distance, not occlusion or body clearance. No spawn damage protection exists. A second baseline problem: before editing any game code, `npm run build` passed (4,678.84 kB HTML / 2,730.53 kB gzip); lint passed but TypeScript reported **three** errors (`RankedSetup` and `rankFor` undefined in App, required `tdm.outcome` missing in ranked end event). Standalone Node suite: **200/201 passed**, failure `tests/mission-integration.test.js:91` pins two empty AI roster construction sites, whereas the checkout now has three (ranked is the third). The tracked `node_modules` was a symlink to itself, so the initial `npm run dev` exited 216; local `npm ci` from the unchanged lockfile restored a working development server. These are **baseline failures**, not regressions introduced by this session.

I read `CHANGELOG.md` and the existing architecture/weapon/mission/scorestreak/sandblast docs first. Prior fixes for real recoil, genuine optic masks, 10-gun models, accurate headshot audio, cover-path AI, mission objective reachability, truthful draw results, 20-draw story maps, volume persistence and synced composer resolution are **not** being re-proposed or reverted. The categories below identify what is still missing. S1 = blocks fun/fairness; S2 = amateur feel or significant friction; S3 = finish. Effort is focused engineering time, **not** a release promise. `[H]` marks this session's headline; `[P#]` marks a committed polish item; other fixes are *not* promised this session.

## Producer's plan for THIS session (approved scope before editing production code)

**Headline [H], S1 — Fair redeploy for Warehouse TDM:** replace distance-only spawn choice with a bounded, symmetric candidate evaluation (nav/capsule clearance, living-body separation, real wall LOS, prefer truly out-of-sight options, still choose the best when trapped). Give both teams a short simulation-time spawn shield when a spawn is exposed; clearly signal it in the HUD/world, expire normally and cancel on attacking. Never apply in ranked rounds or story missions. Player shots, grenades and AI damage must obey the same contract; cover every path and cleanup in a headless 9-bot simulation. Maintain a 5 s respawn and no score/kill for protected hits. Measured before/after: exposed spawns in both 80-case stress scenes; protection TTL/shot cancellation; same world draw/triangle budget.
